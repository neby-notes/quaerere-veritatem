---
title: "Sobre Quaerere Veritatem"
---

Quaerere Veritatem es un proyecto personal dedicado a explorar ideas complejas de manera accesible. Nacido de la convicción de que la verdad es fragmentaria y multidimensional, este garden no sigue una estructura disciplinar rígida sino que se organiza mediante tags que reflejan conexiones conceptuales reales.

El proyecto utiliza tecnologías web modernas para ofrecer una experiencia de lectura limpia y centrada en el contenido:

- **Astro** para generación estática
- **Tailwind CSS** para estilos
- **MiniSearch** para búsqueda en cliente
- **Markdown** como formato de contenido

Todo el código fuente está disponible públicamente.
