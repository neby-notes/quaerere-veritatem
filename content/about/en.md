---
title: "About Quaerere Veritatem"
---

Quaerere Veritatem is a personal project dedicated to exploring complex ideas in an accessible way. Born from the conviction that truth is fragmentary and multidimensional, this garden does not follow a rigid disciplinary structure but is organized through tags that reflect real conceptual connections.

The project uses modern web technologies to offer a clean reading experience focused on content:

- **Astro** for static generation
- **Tailwind CSS** for styling
- **MiniSearch** for client-side search
- **Markdown** as content format

All source code is publicly available.
