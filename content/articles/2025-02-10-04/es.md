# Código y fragmentos técnicos

El código `inline()` se integra en el flujo del párrafo con un fondo sutil y la familia monoespaciada.

## Bloque preformateado

```
function() {
    const valor = 42;
    return valor * 2;
}
```

Párrafo entre bloques.

```
class Demostracion {
    constructor(titulo) {
        this.titulo = titulo;
    }

    render() {
        console.log(this.titulo);
    }
}
```

Otro párrafo. El bloque `pre` tiene borde sutil y esquinas de 4px.
