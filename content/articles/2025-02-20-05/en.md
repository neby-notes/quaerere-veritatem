# Lists and Nested Structures

## Unordered List

- First element with descriptive text
- Second element demonstrating line spacing
- Third element to complete the set
  - Sub-element A
  - Sub-element B
- Fourth element at the same level

## Ordered List

1. First step of the process
2. Second step with more detail
3. Third step almost final
   1. Sub-step 3.1
   2. Sub-step 3.2
4. Fourth closing step

Transition paragraph between lists.

## Mixed List

- General concept A
  1. Ordered detail 1
  2. Ordered detail 2
- General concept B
  1. Ordered detail 3
  2. Ordered detail 4
