# Título Principal (h1)

Este es un párrafo introductorio que acompaña al título principal. Observa cómo el tamaño y el interlineado se adaptan automáticamente al nivel jerárquico.

## Segundo nivel (h2)

El h2 introduce una nueva sección. El espaciado superior es mayor que el inferior, creando un ritmo vertical claro.

### Tercer nivel (h3)

El h3 funciona como subsección. A partir de aquí la escala decrece de forma controlada.

#### Cuarto nivel (h4)

Este es un h4 dentro de la misma sección. Su peso sigue siendo 600 pero el tamaño es menor.

##### Quinto nivel (h5)

El h5 está alineado con el tamaño base del cuerpo pero con peso mayor.

###### Sexto nivel (h6)

El h6 es el nivel más profundo, útil para notas marginales o referencias internas.
