# Estructuras anidadas

## Lista con citas

- Primer elemento
  > Cita dentro de una lista anidada
  
- Segundo elemento
  - Sub-elemento con `código inline()`
  - Sub-elemento con **negrita**

## Tabla con código en celdas

| Función | Descripción | Estado |
|---------|-------------|--------|
| `init()` | Inicializa el sistema | OK |
| `process()` | Procesa datos | OK |
| `cleanup()` | Limpia recursos | Pendiente |

## Bloque de código con lista interna

```
function nestedDemo() {
    const steps = [
        "Paso uno",
        "Paso dos",
        "Paso tres"
    ];
    return steps;
}
```
